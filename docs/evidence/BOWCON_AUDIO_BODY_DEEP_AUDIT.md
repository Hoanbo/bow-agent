## 12. Architecture Contradictions & Gaps

1. **TTS Engine Discrepancy:**
   - Documentation/tests state: *"Local Piper TTS engine generates ultra-low latency response in < 50ms"*.
   - Ground Truth: `src/speech/ttsEngine.ts` generates SSML text markup only (`audioBase64: undefined`). Actual audio generation in `voicePipeline.ts` falls back to Windows SAPI (`System.Speech.Synthesis`).
2. **STT Engine Discrepancy:**
   - Documentation/tests state: *"Local Whisper Vulkan STT"*.
   - Ground Truth: `src/speech/sttEngine.ts` contains a hardcoded return statement `'Xin chào Shop of BOW'`.
3. **Duy Oryx Readiness:**
   - Target Goal: *"TTS voice mục tiêu: Duy Oryx, Voice profile: nam siêu trầm"*.
   - Ground Truth: Model file `duyoryx3175.onnx` is not present on this machine (`NOT_DOWNLOADED`). On the Dual-Xeon machine where it was tested, it failed synthesis on 2 out of 6 sentences with `Piper exit code 1 (Lỗi phoneme)`.
4. **Tool Name Mismatch (Brain vs Body):**
   - In `test_body_audio.ts` (step 6b), privileged voice command "Mở Notepad" triggered `Tool "desktop_launch_app" is not registered in ToolRegistry`. Brain's `ActionPlanner` emits `desktop_launch_app`, whereas `DesktopBody` registers `system.open_app`.

## 13. Blocking Issues

1. **Python Environment Missing on Dev Machine:**
   `python.exe` and `piper.exe` are not installed in PATH on the single-Xeon machine. Any script requiring local Piper execution (`scripts/voice-benchmark/run_benchmark.py`, `synth_duy_oryx.py`) cannot run locally until Python/Piper is provided.
2. **Duy Oryx Phoneme Error:**
   `duyoryx3175.onnx` throws phoneme lookup errors on standard Vietnamese phrases (e.g. "Tôi đã hoàn thành yêu cầu...", "Tôi không thể thực hiện hành động này..."). Model requires a custom phonemizer dictionary or phonetic preprocessing before it can be deployed reliably.
3. **No Pipeline Link for Local Piper TTS:**
   Even if Piper binary and ONNX models are present, `src/speech/voicePipeline.ts` has no logic to invoke Piper. It only calls Windows SAPI.
4. **No Real STT Engine:**
   Real voice interaction is blocked by the hardcoded mock in `src/speech/sttEngine.ts`.
